# Tebogo Earthing & Lightning Protection Services

Ready-to-deploy static website based on the WebDevPro Ultra Max 4 template.

## Deployment
Upload this folder to GitHub and import the repository into Vercel. No build command is required.

## Main features
- Responsive 3-slide hero slider with stable typewriter animation
- Earthing and lightning protection service sections
- Realistic image assets stored locally in `images/`
- Project gallery using supplied site photos
- WhatsApp chatbot and quote links
- Mobile footer menu and PWA install controls
- Multi-page About, Services, Gallery and Contact sections
